# 推广花费 · 方法、用法与踩坑

> 面向“照着做就能跑”的补充文档；页面结构细节见 `dom-contract.md`，流程见 `implementation.md`，实测数字见 `testing.md`。

## 1. 用什么方法（一句话版）

| 目标 | 方法 |
|---|---|
| 近 180 天推广花费 | 打开 `yingxiao.pinduoduo.com/goods/report/promotion/overView?beginDate=YYYY-MM-DD&endDate=YYYY-MM-DD`，关「对比时间」，读右上角数据概览的「成交花费(元)」；再用「财务流水 → 月账单」同月「本月支出」核对，最终取月账单精确值 |
| 更早月份（>180 天） | `https://yingxiao.pinduoduo.com/mains/account/report` → 点「月账单」→ 滚动/翻页找 `YYYY/MM` 行 → 读第 9 列「本月支出」 |
| 截图 | 近期截总览页；老月份截月账单目标行 |
| 校验 | 总览值 vs 月账单本月支出，差 ≤100 元算一致（万显示四舍五入）；老月份看余额恒等式/现金+红包拆分 |
| 落盘 | `<root>/<店铺>/<期间>/`：截图 `<店铺>-推广-<月>月.png`、`推广花费.md`、`账单信息.md` 的 promo 块 |

## 2. 怎么用

```bash
# 近 180 天（整月）
node run.mjs promo.json
# promo.json: {"from":"2026-10-01","to":"2026-10-31","shops":[{"shop":"店铺A","profile":"profile-A"}]}

# 老月份（同样配置，自动切月账单）
node run.mjs promo-2025-09.json

# 自检（只读，不截图/不写）
node run.mjs doctor.json   # {"doctor":true,"from":"2026-10-01","to":"2026-10-31"}
```

- 店铺来源：`shops` 数组或 `<root>/_stores.json`（只写店铺名也可以，worker 会自动找 profile）
- 多店并发：`concurrency`（默认 3）
- 老月份只支持**整月**；跨月/非整月返回 `unsupported_old_range`
- 结果/报告：`<root>/_runs/<runId>/report.json`、`summary.txt`；单店结果含 `spend/overviewSpend/monthlyBill/monthlyMatched`

## 3. 踩过的坑（按现象查）

| 现象 | 根因 | 正确做法/落点 |
|---|---|---|
| 店铺被判 `shop_not_logged_in`，反复扫描 profile | 新版 mms 首页没有 `Header_header_name`，旧读取方式拿不到店铺名 | 以推广页右上角 `[class*='AccountNew_mallName']` 为准；`NavHeader_options` 可能带未读数前缀（`65 店铺C`），需去掉数字前缀。见 `readShopNameFromPage()` |
| 6~8 月金额明显偏小（2.21 / 1.24…） | 卡片是 `2.21 万`，初版没处理「万」单位，读成 2.21 | `parseMoney()` 带单位换算（万 ×10,000，亿 ×1亿）；并拿月账单精确值落盘 |
| 直播/报表页老日期显示 0.00 | 总览只保留最近 180 天，超窗是「暂无数据」，0.00 只是占位 | 老月份走月账单；`no_data` 不写 0.00 |
| 「报表下载工具」点不动/日期改不了 | 它从左侧菜单点会**新开标签页**（`/tools/report/download`），不是当前页跳转；且日期不支持 URL 参数，同样只给近期数据 | 要抓 popup；本 skill 老月份不依赖它，直接走月账单 |
| 月账单列对不上 | 表格 9 列：月份/资金类型/本月余额/=/上月余额/+/本月收入/-/本月支出，`cells[8]` 才是本月支出 | 按 `cells[8]` 取值；不要用列头猜 |
| 月账单找不到 2024 年 | 默认每页 20 条（2026-11 实测共 28 条），第一页只到 2025/03 | 滚动后再点分页 `>`，继续找；`readMonthlyRowOnly()` 已处理 |
| 老月份余额算不平 | 「本月收入」列对旧月份显示 `-`（没展示），不是 0 | 用展开行核对：2024/12 全部 51,848.08 = 现金 51,523.34 + 红包 324.74；余额 840.15 + 收入 53,200 − 现金支出 51,523.34 = 2,516.81 |
| 总览截图里出现 `%`/第二行数字 | 页面记住了上次「对比时间」勾选状态 | 截图/读数前关掉 `input.anq-checkbox-input[1]`；复核卡片不含 `%` |
| 页面复用误判 | 推广页、导出历史、财务页同域，URL 前缀相近 | 不要只看域名；每次显式 `goto` 目标页，或等 `商品推广总览` 文案出现 |
| 截图与文件命名混乱 | 整月/区间/老月份混用 | 统一规则：整月 `<店铺>-推广-<M>月.png`；区间 `<店铺>-推广-<M月D日-M月D日>.png`；期间目录 `YYYY-MM` / `from_to` |
| 月账单 tab 点击无反应 | “月账单”文本可能出现多处（标题/标签） | 取第一个可见精确文本点；等 800ms 后再读表（`switchMonthlyTab()`） |
| 2025-09 曾报 0.00 | 总览超 180 天无数据 | 实测月账单 2025/09 = 3,379.03，与余额恒等式自洽；0.00 是占位 |
| 首次运行报“没有店铺清单” | 旧版本要求手填 `_stores.json` | 0.3.0 起自动扫描 ego profiles 生成（`STORES_DISCOVERED`）；仍找不到才提示登录 |
| 根目录不存在直接失败 | 旧版本要求 `autoCreateRoot` | 0.3.0 起非 C 盘自动创建（`ROOT_AUTO_CREATED`）；C 盘仍拒绝 |
| 店铺没登录只看到 error | 旧版本错误只写日志/报告 | 0.3.0 起 worker 返回 `needs`（question + availableProfiles），runner 打印 `NEEDS=needs_user_action`，退出码 4 |
| 失败/自检后多出空店铺目录 | 旧版 `writeResult` 无条件创建 `<店铺>/<期间>` | 0.3.1 起只有 `done` / `warn` 才创建；失败/`needs`/`doctor` 不落盘 |
| 想看“为什么没核对” | 旧版 report 只有 spend | 0.4.0 起 report 含 `overviewSpend/monthlyBill/monthlyMatched/monthlyBillStatus`；md 里也写核对状态 |
| 老月份截图看不到店铺名 | 月账单滚动后顶部导航被滚走 | 0.4.0 起老月份用 fullPage 截图（含顶部与目标行） |
| 只想快点跑、不想多开月账单页 | 默认核对多一次跳转（约 3~4 秒/店） | 配置 `"verifyMonthly": false`；状态会标「已关闭核对」 |
| 页面加载失败仍退出 0 | 旧版只有 needs 时退出 4 | 0.4.0 起任一 `failed` → `FAILED=job_failed`，退出码 5 |
| 日期没应用却继续读数 | 旧版 `waitDates` 超时后静默继续 | 0.4.1 起回读不一致直接抛 `date_not_applied`（自动重试一次），绝不带错日期读数 |
| 偶发页面/月账单加载慢 | 单次失败就放弃 | 0.4.1 起日期应用、月账单行、店铺发现各重试 1 次；仍失败才报错 |
| 重复跑结果会不会变 | 无幂等跳过（每次重跑覆盖） | 实测 3 店 ×2 次重跑数值完全一致（8.9~13.6s/批） |

## 4. 校验怎么做

- **近期整月**：`总览成交花费` vs `月账单本月支出`；差值 ≤100 元（万显示四舍五入）算一致，否则 `warn`。
- **老月份**：用月账单行自身校验：
  - `本月余额 = 上月余额 + 本月收入 − 本月支出`（老月份收入列可能显示 `-`，需展开行确认）
  - 展开「全部」行 = 「现金」+「红包」两行之和
- **交叉验证过的月份**（2026-06~10，3 店 × 5 月）见 `testing.md`；A/B 店 6~8 月的差异全部来自万取整（50~92 元）。

## 5. 边界与限制

- 总览/报表下载只保留最近 **180 天**（最早 = 今天 − 180 天；随时间滚动）
- 月账单可翻页追溯 2024/01 及更早（实测 2024/12 可读）
- 老区间（跨月/非整月）无法用月账单对应 → `unsupported_old_range`
- 当月未生成月账单时不做核对（`monthlyMatched=null`），使用总览值
- `doctor` 对老月份/暂无数据返回 `doctor_no_data`（只读，不写文件）
- 推广花费口径：成交花费 = 推广总花费；月账单「本月支出」= 现金 + 红包（含虚拟金），近期与总览成交花费一致
