# 测试记录（pdd-promo-cost）

> 环境：Windows，ego lite 0.6.3.14，页面 2026-11-19；时区 Asia/Shanghai。
> 店铺/Profile 已匿名化（店铺A/B ↔ profile-A/B），真实映射只在本机 `_stores.json`。

## 1. 正常采集

| 用例 | 结果 |
|---|---|
| 店铺C 2026-10（鱼越/单店） | done，**成交花费 3,217.62**，总花费 3,217.62，3.9s；截图 `店铺C-推广-10月.png` |
| 店铺A + 店铺C 2026-10 并发（concurrency=2） | 均 done：店铺C 3,217.62（4.2s）、店铺A 9,243.71（4.0s） |
| 三家 2026-09 并发（concurrency=3） | 均 done：店铺C 8,558.67（5.6s）、店铺A 8,956.96（5.7s）、店铺B **1.03**（5.8s） |
| 跨月区间 2026-08-15 ~ 2026-09-10（店铺A） | done，成交花费 **7,692.89**，3.9s；截图 `店铺A-推广-8月15日-9月10日.png` |
| 老月份 2025-09（店铺C，总览无数据） | 自动回退「财务流水·月账单」：**3,379.03**（本月支出），3.8s；截图 `店铺C-推广-9月.png`；与 `上月余额 3,373.19 + 收入 0 − 支出 3,379.03 = 余额 -5.84` 自洽 |
| 更老月份 2024-12（店铺C，需翻页） | done，**51,848.08**（月账单本月支出），5.0s；自动点分页 `>` 后找到行 |
| 对比时间开关 | 采集前自动关掉；截图卡片为单值（无 %），与人工截图一致 |
| URL 日期参数 | 2026-03/2025-09 等超出保留期的日期输入框能回读，但页面「暂无数据」（验证了保留期不是 URL 失效） |

## 2. 协作 / 文件

| 用例 | 结果 |
|---|---|
| `推广花费.md` | 写入店铺/期间/成交花费/总花费/截图/来源 URL/时间 |
| `账单信息.md` | 注入 `<!-- promo:start -->…<!-- promo:end -->` 块 |
| `pdd-bills` force 重跑同期间 | 账单信息重写后 **推广花费块仍保留**（`withPromoBlock` 生效） |

## 3. 性能

- 单店约 **4 秒**（开页 + 关对比 + 读数 + 截图 + 写文件）；
- 两店并发约 4 秒完成（互不阻塞）。

## 4. 数据源与追溯范围

- **商品推广总览**：只保留最近 180 天（最早 = 今天 − 180 天；2026-11-19 → 2026-05-23）；超出则「暂无数据」+ 0.00 占位。
- **财务流水 · 月账单**：按月统计，可翻页追溯到 2024/01 及更早（2026-11-19 实测列表 28 条，最早 2024/12 已能取到）。取「本月支出」作为推广花费。
- 两个来源交叉验证：2026/09 = 8,558.67、2026/10 = 3,217.62，总览与月账单一致。

## 5. 已知限制 / 未测

- PDD 页面改版会导致店铺名元素/指标卡文案/对比复选框结构变化；按 `references/implementation.md` 维护表调整。
- 未做「下载分天数据」；只做截图 + 成交花费读数。
- 老区间（跨月/非整月）无法用月账单直接对应，只支持整月；用到时返回 `unsupported_old_range`。
