# DOM 契约（多多招财 · 商品推广总览）

> 环境：Windows + ego lite 0.6.3.14，页面 2026-11-19 实测。

## 1. 入口

- URL：`https://yingxiao.pinduoduo.com/goods/report/promotion/overView?beginDate=YYYY-MM-DD&endDate=YYYY-MM-DD`
- 标题：`商品推广报表 - 多多招财`
- 路径：多多招财 → 报表 → 商品推广 → 商品推广总览
- 页面结构：顶部导航（概况/推广/报表/工具/营销书院 + 店铺名 + 消息铃）；左侧 报表菜单（商品推广/直播推广/明星店铺/报表下载工具）；右侧数据概览。

## 2. 日期（URL 参数 + 回读校验）

- 主日期区间在右上角：两个 `input[placeholder="开始日期"/"结束日期"]`，value 形如 `2026/10/01`，readonly。
- **URL 参数 `beginDate`/`endDate` 可直接设定区间**，页面加载后输入框同步（2026-03 远月份实测 OK）。
- 页面还有第二组日期：数据概览里的「对比时间」区间（如 `2026/08/31 ~ 2026/09/30`），**不是主区间**，取数/截图都不能用它。
- 日期选择器本体是 `anq-picker`（Ant Design 风格）：
  - 双月面板；每面板按钮：`anq-picker-header-super-prev-btn`（上一年）/`prev-btn`（上一月）/`year-btn` / `month-btn` / `next-btn` / `super-next-btn`；
  - 日期格：`.anq-picker-cell`，本月格带 `anq-picker-cell-in-view`（非本月不带）；
  - 快捷项：今日/昨日/过去7/30/90/180日/本周/上周/本月/上月。
  - URL 参数不可用时，可按上述结构用箭头/月份面板选日期，并回读输入框校验。

## 3. 对比时间开关

- 数据概览右侧有两个复选框（`input.anq-checkbox-input`）：第 1 个「对比指标」、第 2 个「对比时间」。
- 勾选「对比时间」时，指标卡会多出第二行（环比值/百分比），例如：
  `成交花费(元) 3,217.62 ↓66.36% 9,563.63`
- 取数/截图前必须关掉（`boxes[1].checked = false`）；关掉后卡片恢复单值：
  `成交花费(元) 3,217.62`。

## 4. 指标卡读取

- 指标卡是 `div`，文本形如：
  - `成交花费(元) 3,217.62`
  - `总花费(元) 3,217.62`
  - `净交易额(元) 9,244.10`、`净成交笔数 183` 等
- 解析：在卡片文本里用正则 `成交花费\s*(?:（元）|\(元\))?\s*[:：]?\s*([0-9,]+(?:\.[0-9]+)?)` 取第一个数值；
  总花费同理。**不要**扫描整页文本（会把别的卡片/对比值混进来）。
- 判定是否还带对比：卡片文本里出现 `%` 即说明对比没关干净。

## 5. 店铺名

- 右上角店铺名元素：`[class*='AccountNew_mallName']`（文本即店铺名，如 `鱼越贴饰`）。
- 兜底：`[class*='NavHeader_options']`（可能带消息未读数前缀，如 `65 鱼越贴饰`，需去掉数字前缀）。
- 校验店铺名与配置一致；不一致时报错，不串店。

## 6. 截图与文件

- 截图：整页 viewport 截图；命名 `<店铺>-推广-<月>月.png`（整月）或 `<店铺>-推广-<M月D日-M月D日>.png`（区间）。
- 同期目录里还有 `推广花费.md` 与 `账单信息.md`（后者由本 skill 注入/更新 `<!-- promo:start -->…<!-- promo:end -->` 块）。
- 页面没有浏览器下载文件需求；本模块不点「下载分天数据」。
